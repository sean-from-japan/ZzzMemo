# ZzzMemo

**AIエージェントが使うことを前提にした、個人用のメモ帳です。** 人は1行ずつ書くだけで、書いた行は後からAIエージェント（Claude Code、Codex、MCPに対応したクライアント）がタスク・メモ・欲しい物に仕分けます。アプリの中にLLMは入っていません。

![今日の画面。大きな入力欄、今日書いた行と仕分けの状態、期日のあるタスクが並ぶ](docs/screenshot.png)

## この形にした理由

最初の版ではGeminiをアプリに組み込み、タスクごとに分類・期日・優先度を選ぶ作りでした。書き留めるのは続いても、仕分けて整理する手間のほうが続きませんでした。そこで第2版では、書く人と仕分けるエージェントで作業を分けています。

書く側の手間は、入力欄に1行打ってEnterを押すことだけです。「郵便局　荷物」のような書きかけの行でかまいません。

その行は、Claude Codeなら `/zzz` のようなコマンドで頼んだときに、エージェントがまとめて読みます。タスクなら期日を付け、買う物なら欲しい物へ移します。すぐに仕分ける必要はないので、サーバーにはLLMもそのAPIキーも置いていません。

タスク・メモ・欲しい物・チェックリストの4種類は最初から使えます。読みたい本のように新しい種類が要るときは、エージェントが項目（著者、状態など）を決めて提案し、本人が確認の画面で承認してから使えるようになります。種類の定義はデータベースに入っていて画面もそこから作るので、種類を増やすたびにコードを直す必要はありません。

調べごとの結果や英語のスクリプトのように、エージェントが作って本人が読むだけのHTMLやPDFも置けます。項目の型に「ファイル」があり、その種類（たとえば「資料」）の項目を一覧で押すと、アプリの中の読む画面で開きます。`.slide` で区切ったHTMLは1枚ずつ表示し、前へ・次へと矢印キーで送れます。資料のHTMLは出どころを持たない隔離された状態で開くので、中のスクリプトはボタンなどページの中の操作には使えますが、ログインのクッキーやAPIには触れません。記入式のページが `localStorage` に保存する内容（答えやチェック）は、アプリの読む画面で開いたときに限り、項目ごとにサーバーへ保存され、次に開いたときに戻ります。

エージェントの変更も含めて、書き込みはすべて変更前と変更後の形で記録しています。仕分けが気に入らなければ、確認の画面から1件ずつ戻せます。

## 画面

| 画面 | 使い道 |
|---|---|
| 今日 | 入力欄と、今日（または過去の日）に書いた行とその状態（未処理・仕分け済み・判断待ち）。3日以内に期日が来るものと、未完了のタスク。ファイルのある項目（資料）を、ピン留めしたもの・最近開いたもの・新しいものの順に6件。 |
| 一覧 | 種類ごとの一覧。編集欄は種類の項目から作ります。 |
| 読む | ファイルのある項目を開いたときの画面。上に戻る・題名・再読み込み・ピン・メモ・詳細・別のタブで開くを置き、残りは資料を表示します。メモは項目のメモ欄と同じもので、資料の横（スマホでは下）に開き、書くと自動で保存されます。 |
| 確認 | エージェントが提案した種類と種類の変更（分類の選択肢を増やすなど）の承認と却下、エージェントが決められなかった行、変更の記録と取り消し。 |

PWAなので、スマートフォンのホーム画面に追加できます。明るい配色と暗い配色は端末の設定に合わせます。

## エージェントにできること

エージェントが何と名乗っても、扱いはリクエストの認証のしかたで決まります。

| | 本人（ブラウザのログイン） | エージェント（APIキーか `X-Actor` ヘッダー） |
|---|---|---|
| 行と項目の追加、項目の編集 | できる | できる |
| 行を仕分け済み・判断待ちにする | できる | できる |
| 本人が書いた行の書き換えと削除 | できる | できない（403） |
| 種類の追加 | できる | 提案だけ。承認されるまで使えない |
| 提案の承認と却下 | できる | できる。本人に頼まれたときだけ（`decide_proposal`） |
| 一覧で大きなカードにする種類 | できる | できる（`set_main_kind`） |
| 種類の変更と削除 | できる | できない（403） |
| 変更の取り消し | できる | できる。種類に関するものは除く |

## エージェント用の道具

`mcp_server.py` に18個のツールがあります。確認画面でできる提案の承認と却下も `decide_proposal` でできるので、画面を開かずにCLIだけで進められます。手元のHTMLやPDFを上げて項目にする `add_file` もその1つで、同じ題名の資料があればファイルを差し替えます。同じツールは追加のパッケージなしでコマンドとしても動くので、MCPサーバーを登録しなくても、スラッシュコマンドやCodexから使えます。

```bash
python mcp_server.py list
python mcp_server.py call list_unsorted '{}'
```

MCPサーバーとしての設定例は [README.md](README.md#tools-for-agents) にあります。mcp 1.x と 2.x のどちらでも動きます。

## 動かす

Python 3.10以降で動きます。

```bash
git clone https://github.com/sean-from-japan/ZzzMemo.git
cd ZzzMemo
pip install -r requirements.txt
python qcatch.py          # http://localhost:5000（手元ではログイン不要）
python -m pytest tests
```

ログインの設定（パスワード、Googleでのログイン、エージェント用のAPIキー）は環境変数で行います。一覧は [README.md](README.md#run-it) にあります。Googleでのログインで受け取る情報は、メールアドレスだけです。ログインを何も設定せずに外部から届くアドレスで起動しようとすると、サーバーは起動しません。

## 構成

サーバーは FastAPI と SQLite です。画面はHTML 1枚とJavaScript 1ファイルで、フレームワークもビルドも使っていません。ファイルの一覧は [README.md](README.md#stack) にあります。
